# Academy Cloud Java

그린컴퓨터아카데미 역삼점의 **클라우드 활용 자바 스프링 프레임워크 개발자 과정**을 수강하며 작성한 학습 및 실습 코드입니다.

Java 기초 문법부터 객체지향 프로그래밍, 데이터베이스 연동, 웹 개발 기초까지 과정 중 배운 내용을 주제별로 정리했습니다.

## 주요 학습 내용

- Java 기본 문법, 배열 및 메서드
- 클래스, 생성자, 상속, 추상 클래스 및 인터페이스
- 컬렉션과 예외 처리
- 파일 입출력
- AWT를 활용한 화면 구성
- JDBC를 이용한 데이터베이스 연동
- HTML, CSS 및 JavaScript 기초
- JSP와 XML 기반 웹·데이터베이스 실습

## 사용 기술

- Java
- JDBC
- JSP
- HTML
- CSS
- JavaScript
- SQL
- XML

## 학습 목적

교육 과정에서 배운 내용을 직접 코드로 작성하고 복습하며, Java 기반 웹 개발에 필요한 기초를 익히기 위해 만든 저장소입니다.
